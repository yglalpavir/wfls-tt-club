# 简化个人数据导出卡片 — 实施计划

## 目标
把当前 900×~3000px 的"整页报告"式战绩卡，精简为约 1100px 高的**精简卡**：资料头 + 总览 7 数字 + 积分走势图 + 标签/荣誉（去掉与资料头的重复）+ 对手分析四卡 + 竞技状态卡（含近10场圆点与7日滚动小图）。裁掉深度分析区的 6 个重型图表（排名走势/类型分布/实力差/月度活跃/赛季对比/积分来源构成）与摘要句。

## 改动范围：仅 `js/player-page.js`（一个函数为主）

`buildPlayerExportNode(player)` 从"三段整取"改为**选择器驱动的精选组装**：
1. `.player-profile`（资料头，含姓名/UID/状态/积分/排名/标签/荣誉）——保留
2. `#playerStatsBody` 内仅取：
   - `.personal-overview`（7 项总览数字）
   - `.personal-chart-section`（积分走势图；粒度切换按钮已剔除逻辑保留）
   - `.personal-cards-grid`（对手分析四卡）
   - **不取** `.personal-summary-text`（摘要句）和 `.personal-tags-honors`（与资料头重复）
3. `#playerAnalyticsBody` 内仅取 `.pa-form-body` 所在的 `.pa-card`（竞技状态卡：当前连胜/最长连胜连败/近10场圆点/7日滚动 spark 图），`closest('.pa-card')` 定位，不存在则跳过
4. 页脚（链接 + 生成时间）与头部标题行不变

## 顺带修正与保留
- **canvas→img 转换改为按 id 匹配**：克隆里出现的 canvas 用 `document.getElementById(canvas.id)` 找源画布（原来按区块顺序 zip 匹配，精选区段后顺序对应会失效）；匹配不到的画布直接移除。仍保留 `chart.update('none') + draw()` 强制重绘（后台标签页防空白）。
- 保留现有全部防护：glass-card 毛玻璃中和、`.pa-form-dot` 圆点 canvas 预渲染、图表容器高度自适应、`text-autospace: no-autospace` + `font-kerning: none`（导出核心内）、CSS zoom 反向抵消。
- 出口函数 `exportPlayerShareCard` 不变；`renderPlayerExportButton` 不变；不新增 i18n key。
- `personal-stats.js` 的 `computePersonalStatsData` 保持不动（继续为页面渲染服务）。

## 验证（本地 no-cache 服务器 + 浏览器）
1. `player.html?uid=10000` 真实点击导出 → 下载成功、无报错弹窗、按钮恢复
2. 渲染 PNG 全图检查：布局、圆点居中、混排无空隙；高度约 1100px 量级
3. 暗色主题渲染检查
4. CSS zoom 1.25 场景抽检（反向抵消逻辑未动）
5. 详情页导出不涉及本次改动，回归一次确认无连带影响（c6）

## 不做
- 不动详情页导出、不动排行榜导出、不动个人数据页本身的展示。
