# 计划：WTT 模块导入欧锦赛（European Table Tennis Championships）比赛数据

日期：2026-10-17
范围：`wtt_data/{ms,ws,md,wd,xd}`（国际乒联积分排名中心 / WTT 模块）

## 1. 目标

把欧洲乒乓球锦标赛（欧锦赛，ETTU 主办的 European Table Tennis Championships）的
逐场成绩写入 WTT 模块，与已有的 `洲杯赛`（欧洲 Top 16）等洲际赛事并列。

- 赛事类型映射：**个人赛** → `洲锦赛`；**团体赛** → `洲锦赛团体`。
- 项目映射：MS→`ms`、WS→`ws`、MD→`md`、WD→`wd`、XD→`xd`；
  团体赛的 MT/WT 双方单打场次分别写入 `ms` / `ws`，类型为 `洲锦赛团体`。
- 记录格式沿用 WTT 既有约定：`{日期, 类型, 胜者, 负者, 比分?, 局分?}`，
  其中 `局分` 为**胜者视角**的每局比分（如 `["11-9","8-11","11-6"]`）。

两项前置结论已核实：

1. `洲锦赛` / `洲锦赛团体` 系数已在各项目 `event-coefficient.json` 中定义
   （ms/ws：`洲锦赛 1.21`、`洲锦赛团体 0.81`；md/wd/xd：`洲锦赛 0.6`、`洲锦赛团体 0.4`），
   `ci_validate.py` 要求记录类型必须是该项目系数字典的数值键，因此**无需新增系数**。
2. i18n 键 `wtt_ev_continental_champs`（洲锦赛）/ `wtt_ev_continental_team`（洲锦赛团体）
   已在 `js/common.js` 中就绪，**无需新增翻译**，EN 模式也不会漏中文。

## 2. 数据源

ETTU 官方成绩平台 = TTM WebGen 静态站点 `https://www.ttm.co.at/results/<slug>/`。
每个 slug 有 `dates.html`（比赛日列表）与 `YYYY-MM-DD.html`（当日全部场次），
内容是**预生成的静态 HTML**，无需 JS 渲染即可直接抓取。

本次采用的数据源与本地缓存：`tools/.eu_champs_raw/`（一次性抓取脚本 `tools/_eu_probe.py` 已缓存）。

- **2016 / 2018 个人赛**：ETTU 无存档，改用二手来源 allabouttabletennis.com（AATT）补录；
  早期轮次只有局数（如 `4-1`）没有逐局比分 → 这些场次只写 `比分`。

## 3. 记录口径（与仓库约定对齐）

- **团体赛记录为个人单打场次**（先例：`世乒赛团体`、`亚运会团体` 均为个人场次行），
  因此 `洲锦赛团体` 同样写个人场次，MT→`ms`、WT→`ws`。
- **未开打场次必须跳过**（`td.result` 两侧为空），这些是签表占位。
- 团体赛的「球队行」（带 `data-bs-toggle="collapse"` 的 tie 行）不产生记录，
  只作为分组边界；其后的 `tr.individual` 才是记录。
- **双打组合名规范化**必须与 `js/wtt_common.js` 的 `wttNormalizeDoublesName()` 一致：
  MD/WD 按字典序升序；XD 男先女后（性别未知时退回字典序）。
  性别表从 `js/wtt_common.js` 的 `WTT_KNOWN_GENDERS` 解析。
- **球员姓名**：TTM 原始格式为 `姓, 名`（姓全大写，如 `SZOCS, Bernadette`），
  转换为仓库标准 `名 姓`（`Bernadette SZOCS`）。
  仓库内不同来源的姓名拼写并不一致，因此以外键归一化（去音标/去标点/小写，
  先整串比较、再按词集合比较）在**现有 wtt_data 姓名表**中反查标准拼写；
  查不到的保留转换结果并**打印待人工确认清单**，只在必要时加显式覆盖表。
- 单打项目（ms/ws）记录名**不得含 `/`**；双打项目必须是「恰好两人的 `A/B`、
  两人不同、且胜者与负者的成员集合不同」——这是 `ci_validate.py` 的硬规则。

## 4. 实施步骤

1. 写 `tools/import_europe_champs.py`（局部脚本，`.gitignore` 已忽略 `tools/*`，仅本地保留）：
   - 从 `tools/.eu_champs_raw/` 读取缓存的日页（可选 `--fetch` 主动补抓）；
   - 按 `tr.header` / `tr.match` / `tr.individual` 行结构解析出场次；
   - 生成 `比分`（必带）与 `局分`（仅当每局都能解析且与局数一致时才带，
     否则只留 `比分`，与 `ci_validate.py` 的校验规则相容）；
   - 姓名与双打组合名规范化；
   - 幂等追加（按 `(日期, 类型, 胜者, 负者)` 去重），新建年度文件时登记 `manifest.json`；
   - `--check` 只解析报告不落盘，`--dry-run` 展示将要写入的内容。
2. 先 `--check` 跑一遍，人工核对计数与「新姓名」清单。
