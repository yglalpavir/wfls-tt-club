# Bornan（ITTF 官方成绩站）ITTF 时代缺口导入报告

日期：2026-10-27 · 工具：`tools/bornan_catalog.py`（目录枚举）、`tools/import_ittf_era.py`（导入器）

## 1. 背景与范围

目标：把 ITTF 时代五类赛事（公开赛、洲际锦标赛、世界杯、奥运会、世界锦标赛）的缺口
从 Bornan 静态 JSON 平台（`results.ittf.com/ittf-web-results/html/<目录>/`）补齐，
五项（ms/ws/md/wd/xd）全导，**已有的一律不导入**，数据源只用 Bornan。

导入前本地已有（普查确认，跳过）：2001–2005（ittf公开赛/世乒赛/世界杯/奥运 2004/总决赛）、
2013–2017（常规赛/白金赛/世乒赛/世界杯/奥运 2016/总决赛/洲锦赛部分）、
2018–2020 的洲锦赛/洲杯赛、2021 起现行体系（奥运 2020/2024、世乒赛 2023/2025 + 团体 2022/2024、世界杯 2024+、WTT 系列）。

## 2. Phase 0 —— Bornan 平台目录枚举

- 平台：Azure Blob（`saittfwebresults.blob.core.windows.net/ittf-web-results`），公开列举开放。
- 全平台共 **506 个赛事目录**（命名宽度混乱：`TTE3474` / `TTE02896` / `TTE2577` / `TT2977` / `2876`，个别目录无 champ.json：TT2977、TTE2904、TTE2987、TTE5482、TTE8765）。
- **平台存档范围：2018 年起**（2022+ 的 WTT 系列赛事也在此平台，但不在本次五类范围内）。
- 按 `champDesc` 归类并排除青少年/区域/残障/资格赛/WTT 系列后，五类目标 **80 个赛事**（`tools/.bornan_catalog/targets.json`）。

- **2001 年初**（大阪世乒赛、世界杯 2001、年初公开赛）：平台无。

## 5. 导入口径

- 记录 = `{日期, 类型, 胜者, 负者, 比分?, 局分?}`（胜者视角），与既有 wtt_data 完全一致。
- 类型映射：普通站→`ittf常规赛`、Platinum 站→`ittf白金赛`、Challenge 站→`常规挑战赛`、总决赛→`总决赛`、世乒赛→`世乒赛`（团体 tie→`世乒赛团体`）、世界杯→`世界杯`（团队→`世界杯团体`）、洲锦赛→`洲锦赛`（tie→`洲锦赛团体`）、洲际杯→`洲杯赛`。
- WO/RET/未完场跳过；逐局比分（Splits）→ `局分`（与 Res 冲突时按逐局采信，沿用亚锦赛导入器口径）。
- 双打：MD/WD 成员按字母序，XD 未知性别退化字母序 —— 与运行时 `wttNormalizeDoublesName` 规范化结果一致（性别表 `WTT_KNOWN_GENDERS` 仅覆盖 WTT 时代球员，老一代混合双打因此按字母序入账，与前端内存形态一致）。
- 姓名经 `pick_name`（`import_asian_champs.py` 同管道）归一到仓库口径；未命中现有姓名表的新球员逐一登记进导入器 `NAME_OVERRIDES`（疑似同人的模糊命中统一到既有写法，均已在登记行注释标明）。
- 去重键 `(日期, 类型, 胜者, 负者)`；同日同对阵多场为合法记录，不合并。
- 新建年份文件自动登记 `manifest.json` + 补 `seasons.json` 赛季（2006–2012 赛季早已预注册，实际未用到——平台无该年段数据）。

## 7. 姓名口径

- 全部新球员经 `pick_name`（ITTF 原始「姓 名」→ 仓库口径）+ 952 条 `NAME_OVERRIDES` 人工登记：
  - 7 组音译同人统一到既有写法（Adem/Adam HMAM、Aliaksandr/Aleksandr KHANIN 等，见导入器注释）；
  - 19 组挑战赛阶段的模糊命中一律保守保留为新球员（不合并），含「CHOE Hyon Hwa (1998)」这类出生年区分（沿用仓内「姓名 (出生年)」惯例）；
  - 「^^」等 Bornan 姓名杂质已清理，出生年括号保留。
- `xd` 双打对老一代球员按字母序入账（`WTT_KNOWN_GENDERS` 仅覆盖 WTT 时代球员），与前端 `wttNormalizeDoublesName` 内存形态一致。
