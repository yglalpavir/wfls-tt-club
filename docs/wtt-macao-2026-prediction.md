## 二、签表与赛制

**赛制**：全程五局三胜（bo5，先胜 3 局者胜）。本报告的"系列概率"均按 bo5 闭式解计算：

$$P(\text{胜系列})=\sum_{j=0}^{n-1}\binom{n-1+j}{j}p^{n}(1-p)^{j},\quad n=3$$

### 2.1 由赛程表推断出的签表

用户提供的 16 场 R32 按公布顺序排列，种子恰好落在第 1、4、5、8、9、12、13、16 场（即 0/3/4/7/8/11/12/15 号槽位）。这个分布满足标准 32 人抽签的全部成对约束（1 与 2 不同半区、1 与 3 不同半区、1 与 4 不同 1/4 区、1 与 5 同 1/4 区……），按"公布顺序即抽签顺序、相邻两场在签表上相邻"这一常规读法即可还原出下面的签表；区内的 R16 配对取 (0,1) 对 (2,3) 是唯一能让每区两枚种子分居两条分支、从而最早在 QF 相遇的排布：

| | R32 第 1 组 | R32 第 2 组 | 1/4 区种子 |
|---|---|---|---|
| **Q1**（上半区） | MATSUSHIMA (1) / JARVIS　UDA / WONG Chun Ting | PUCAR / RASSENFOSSE　LUM / CALDERANO (5) | 1、5 |
| **Q2**（上半区） | LIN Yun-Ju (4) / COTON　KALLBERG / SHAH | KUO Guan-Hong / DUDA　THAKKAR / LEBRUN (6) | 4、6 |

半区：上半区 {Q1, Q2}、下半区 {Q3, Q4}。每个 1/4 区两枚种子分居两条 R16 分支，因此同区两枚种子最早在 QF 相遇——这正是「CALDERANO vs MATSUSHIMA」成为最可能 QF（16.6%）的原因。

## 三、数据与方法

### 3.1 信源

所谓"多信源"，本报告指的是**同一份历史战绩数据上的 7 个独立估计口径**（外加 1 个规则派生口径）：

| 信源 | 口径 | 逻辑 |
|---|---|---|
| BT-λ1.0（全期） | Bradley-Terry，series 似然 + 岭正则 λ=1.0 + Σμ=0 | 直接对"赢系列"似然做极大似然，IRLS 对角自然梯度求解 |
| BT-λ0.3 | 同上，λ=0.3 | 弱正则，对低样本选手更激进 |
| BT-λ1.0（近 12 月 / 近 24 月） | 同上，按比赛日期截窗 | 只看近一年 / 近两年 |
| Elo-经典 | 逐场 K=32 的 Bernoulli Elo | 把系列当成独立局来更新，未做赛制修正 |
| Elo-赛制 | 赛制感知 Elo：系列按 `series_prob` 的 pdf 更新 | 与"bo5 赢一局和 bo7 赢一局价值不同"这一事实一致 |
| Elo-赛制（H=180d / 近 12 月 / 近 24 月） | 赛制 Elo + 指数时间衰减 H=180 天 / 日期截窗 | 近期表现加权 |
| 官方积分-全期 / 本赛季 | **复现 `js/score-engine.js` 的 WTT 口径** | `SCORE_TIME_DECAY_ENABLED=false`、`LOSER_POINT_MULTIPLIER=1.0`、`DEFAULT_INITIAL_SCORE=1500`、`SCORE_FLOOR=1200`、`getBaseScore` 分档、按赛事系数（冠军赛 0.83）逐场滚动 |
| 三因子（站点口径） | 0.7·Elo + 0.3·近况，或 0.6·Elo + 0.2·H2H + 0.2·近况 | 沿用 `docs/predicted-win-rate.md` 的口径；H2H 用 Laplace 平滑 (w+2)/(n+4)，近况为最近 10 场积分净变化经 k=0.02 sigmoid |

"官方积分"这一路是把本站点排行榜的真实算法在本地重算——因为本环境无法访问 world-table-tennis.com（DNS 解析失败，详见第六节），只有本站点自己的实现可作为"官方口径"的代理。

### 3.2 验证方式

**时间序 6 折交叉验证**，训练集严格早于测试窗口起点，无未来信息泄漏：

| 折 | 测试窗口 |
|---|---|
| 1 | 2025-04-01 → 2025-06-30 |
| 2 | 2025-07-01 → 2025-09-30 |
| 3 | 2025-10-01 → 2025-12-31 |
| 4 | 2026-01-01 → 2026-03-31 |
| 5 | 2026-04-01 → 2026-06-30 |
| 6 | 2026-07-01 → 2026-09-07 |

评分用 **Brier 分数**，标签取"模型更看好的一方"，事件为"该方是否真的赢下系列"（这样 Brier 才在 0.25 的无信息基线附近可比，而不是在 `p²` 附近退化）。三个评估子集：

- **全量**（n=4,164）：所有双方都在训练集中出现过的测试比赛
- **活跃**（n=2,247）：训练集中至少 30 场的选手——本报告的主要评估口径，也是本届 32 人中的绝大多数
- **精英**（n=1,132）：只保留 `ittf白金赛 / 世乒赛 / 世界杯 / 冠军赛 / 大满贯 / 奥运会 / 总决赛 / 球星挑战赛` 这 8 类赛事——最接近本届冠军赛的对抗强度

### 3.3 主模型 M*

**M* = BT-λ1.0（全期）+ Elo-赛制（全期）+ BT-λ1.0（近 24 月）的 μ 均值，不做收缩**。它是 18 个候选中在"活跃"和"精英"两个子集上同时最优的（Brier 0.2030 / 0.1981），且三个成员的 CV 表现彼此相近，属于稳健的集成而非单点最优。所有出场概率均由 M* 的 μ 差经 `series_prob(sigmoid(Δμ), 3)` 得出。

### 4.2 三个关键发现

**① 全历史胜过近期。** 这是与直觉相反、但数据一致给出的结论：所有"全期"口径（BT 0.2061、Elo-赛制 0.2083、M* 0.2030）都优于对应的"近 12 月 / H=180d"口径（0.2116 / 0.2164 / 0.2181）。乒乓球职业选手的技术水平相当稳定，近一年样本（活跃选手约 30–68 场）远小于全期（100–372 场），信噪比反而更低。**"近况"在这份数据里是噪声而不是信号。**

**② 收缩（shrinkage）在这个场景下有害。** 常见的"把概率向 0.5 收缩以提高校准"的做法，在本数据上单调变差（近况集成收缩 1.0 → 0.1 对应活跃 Brier 0.2100 → 0.2396）。原因是收缩的代价与收益不对称：模型确实轻度过度自信，但幅度只有 3–5 个百分点（见 4.3），而收缩 0.1 会把一个 0.95 的判断硬拉到 0.545——纠正了 4 个百分点的偏差，却引入了 41 个百分点的偏差。Brier 对偏离真实概率的距离按平方惩罚，因此大幅度的"拉平"远比小幅度的"高估"昂贵。

**③ 官方积分榜是 18 个口径中最差的一个。** 全期 0.2274、本赛季 0.2352，明显劣于任何 BT 或赛制 Elo。根因是它的记账方式是**无时间衰减的累加**（`DEFAULT_INITIAL_SCORE=1500`、`LOSER_POINT_MULTIPLIER=1.0`、`SCORE_FLOOR=1200`、`SCORE_TIME_DECAY_ENABLED=false`）：每一场都按"与对手的积分差分档 × 赛事系数"直接累加到总分上，场次越多累积的增益越多，于是生涯场次本身成了排名的一部分。HARIMOTO 2,151 分来自 372 场，MATSUSHIMA 2,178 分来自 226 场，而 ZHOU Qihao 只打了 139 场就是 1,898 分、Dang QIU 191 场是 1,787 分——同一水平段差出 300 分以上的积分，几乎全是样本量差而不是实力差。用它做单源模拟，夺冠概率会坍缩成 MATSUSHIMA 45.7% / HARIMOTO 42.7% 的"两人天下"（合计 88.4%），这是样本量偏差的极端体现。

## 五、不确定性

### 5.1 参数不确定性（bootstrap）

对全量 21,657 场做 case bootstrap，重拟 50 套 M* 参数、每套跑 3,000 次签表模拟（共 150,000 次），得到夺冠概率的抽样分布：

## 六、局限与免责

1. **无外部实时信源。** 本环境无法访问 world-table-tennis.com（DNS 解析失败）与 Wikipedia（连接超时），因此**没有**引用官方实时排名、博彩赔率、伤病情报或近期热身赛成绩。本报告的全部"多信源"都是同一份本地历史战绩（`wtt_data/ms/score-log-*.json`，21,657 场）上的不同估计口径。若纳入赔率或官方排名，最可能改变的是 0.5–0.7 那几场硬币局的判断。
2. **签表是推断的。** 见 2.1 的说明。签表结构直接决定 MATSUSHIMA 的夺冠概率上限，这是除模型选择外最大的结构性假设。
3. **只有系列结果，没有局分。** 数据集中每条记录只有胜者/负者/日期/类型，没有 3–1 / 3–2 / 3–0 的局分分布，因此只能用 series 级似然建模，无法估计"局内实力"，也无法对 3–2 险胜与 3–0 横扫做区分。这直接导致 1.4 中两场 3–2 冷门的预测误差无法被模型内部吸收。
4. **小样本选手。** MAK Tin Ian 在数据集里只有 3 场（全部是 09-08 的 R32），HUANG Youzheng 80 场、Tom JARVIS 76 场、Flavien COTON 45 场、KUO Guan-Hong 50 场、Nicholas LUM 34 场。他们的 μ 估计方差远大于主力选手；bootstrap 区间（sd 2–5.5%）只反映了参数不确定性，**不包含签表推断错误和数据陈旧（最近一场比赛 2026-08-16 至 2026-09-08）带来的偏差**。
5. **状态因素不可见。** 数据集中没有伤、病、退赛、签证、时差、赛程密度等信息。TOGAMI 最后一场是 09-06、MATSUSHIMA 是 08-16、MOREGARD 是 08-11——间隔差异可能意味着状态差异，模型对此完全没有捕捉。
6. **概率不是赔率。** 这些数字是"如果模型正确"条件下的估计，不能直接当投注依据：CV Brier 0.20 相对 0.25 的无信息基线只是好 20%，并不意味着任何单场有 80% 的把握。已完赛 7 场里 2 场爆冷（经验爆冷率 28.6%），而模型对那两场的自报置信度是 62.3% 与 73.0%——**模型的自报不确定性系统性地低于实际爆冷频率**，这是把概率当赔率使用的最主要风险。
7. **本报告不构成任何形式的投注建议。** 仅供本俱乐部球迷参考与赛后复盘。

```bash
python tools/_wtt_macao_audit.py    # ~1s，核对报告与 JSON 是否一致
```

**已修复的四个实现缺陷**（复现时不要回退）：
- `series_pdf` 原先用 `lgamma(2n-1)` 而非 `lgamma(2n)`，少了一个 `(2n-1)` 因子；已与数值差分对齐验证。
- 交叉验证的 Brier 原先以"实际胜者"为标签，等价于度量 `p²`（模型预测的方差），会得出"收缩永远更好"的假结论；改为以"模型看好的一方"为标签后，结论完全反转（收缩有害），且无信息基线落在 0.25。
- 模拟器的 QF/SF 层原先把**跨 1/4 区**的 R16 胜者配对，导致每个 1/4 区可能贡献 0 或 2 个 SF 参赛者（违反签表结构）。现已改为"同区两场 R16 胜者对决 → 区幸存者 → 同半区两个幸存者打 SF"，并加入结构不变量断言（每 1/4 区恰好 2 个 QF 席位与 1 个 SF 席位，容差 1e-9）。
- 晋级概率原先直接取"席位占比"（除以席位总数），导致 R16/QF/SF/决赛四列的总和都是 1.0，从而出现"进 SF 概率高于进 QF 概率"这种不可能的结果（如 LEBRUN 12.16% > 8.51%）。现乘以席位个数（16/8/4/2）换算为真实概率，并加入单调性断言（进 QF ≥ 进 SF ≥ 进决赛 ≥ 夺冠）。**冠军分布与各轮对阵频率不受此影响**——每次模拟只有 1 个冠军、每场对阵只出现一次。

**如何复现**：

```bash
python tools/_wtt_macao_run.py     # ~20s，输出 tools/_wtt_macao_models.json
python tools/_wtt_macao_sim.py      # ~3.5min，输出 tools/_wtt_macao_sim.json
```

依赖：Python 3 + numpy（无需 scipy，所有组合数与对数似然用 `math.lgamma` 手算）。
