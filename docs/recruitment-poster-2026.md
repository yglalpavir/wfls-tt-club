### 区块 7 · 新手 FAQ

**Q：我零基础 / 打得菜，能加入吗？**
A：能。社团理念就是"从'菜鸟'成长为'大神'"——1300 的初始分对所有人一视同仁，友谊赛随时可打、照样计分，你只需负责变强。

**Q：没有球拍怎么办？**
A：球拍等器材问题欢迎入群咨询，学长学姐会给你建议。

**Q：积分是怎么算的？会不会对新手不友好？**
A：ELO 变体算法：对手越强、赢得分越多（鼓励挑战强者）；输球只按胜者得分的 0.8 倍扣分，且有 1200 分保底地板——放手打，亏不了。

**Q：在哪里看排名和比赛记录？**
A：社团官网（见下方二维码旁网址）——Ranking 页看实时排名，个人数据页看你的积分走势、胜率和全部对局记录。

## 第二部分：排版设计建议

### 尺寸与整体布局

建议 **A4 竖版**（班级后墙、门板张贴）或 A3（更醒目）。自上而下六个视觉层级，信息密度从主视觉向加入方式递增：

```
┌─────────────────────────────┐
│  ① 主标题 + 主口号（蓝底白字横幅，占 18%）   │
│  ② 一句话简介（居中，占 8%）                 │
│  ③ 数据卡 ×4（等宽横排，占 12%）             │
│  ④ "在这里你可以" 四板块（左右两栏网格，占 30%）│
│  ⑤ 时间地点表 + 荣誉墙（左右两栏并排，占 18%） │
│  ⑥ FAQ（窄栏小字，占 8%）                    │
│  ⑦ 二维码 + 官网 + 落款（右下角强调区，占 6%） │
└─────────────────────────────┘
```

### 配色（与官网主题一致）

| 用途 | 色值 |
|---|---|
| 主色（横幅、标题、卡片描边） | `#007bff` |
| 深蓝（渐变收尾、强调标题） | `#0056b3` |
| 浅蓝（背景衬底、卡片底色） | `#e6f2ff` |
| 强调色（数据数字、"冠军"字样） | 红 `#ff4d4f`、金 `#f0a500` |
| 正文文字 | `#1a1a2e`（深灰蓝） |

### 字体与字号（A4 参考值，A3 按 √2 放大）

- 字体：中文 **Noto Sans SC / 思源黑体**（官网同款），英文数字 **Poppins**；
- 主标题 ≈ 60–70pt 加粗；主口号 ≈ 34pt；区块标题 ≈ 20pt；正文 ≈ 11–12pt；FAQ 与注脚 ≈ 9–10pt；
- 数字卡片中的大数字（44 / 244+ / ELO / 1）用 Poppins Bold ≈ 40pt，配 10pt 说明文字。

### 二维码与官网

- 二维码源文件：仓库内 `Assets/images/qr-code.jpg`（群二维码定期更新，**印刷前确认取到最新版**）；
- 成品尺寸建议 ≥ 3×3cm，置于白色衬底块上，正下方配文字"扫码加入社团 QQ 群"；
- 官网地址两行展示效果更好：第一行"更多规则与战报"，第二行加粗网址 `yglalpavir.github.io/wfls-tt-club`。

### 其他细节

- 数据卡片建议加 1px 蓝色描边 + 浅蓝底，四卡等宽横排；
- 荣誉墙的奖牌 emoji 可替换为真实照片（2026 校乒赛照片见官网 competitions 页）；
- 如需双语，主标题下加 "WFLS Table Tennis Club" 即可，正文无需双语（受众为校内学生）；
- **不要**在海报上出现任何个人 QQ 号——统一以 QQ 群二维码为唯一联系方式。
